# DataRecruit concept demo

Fictional data and a simulated assistant. No accounts connected, no messages sent. Imported records and the learning demo stay in memory and disappear on refresh. Publicly accessible compiled demo only.

Built from private source checkpoint b89d941 (candidate progression in the match review, on top of the CV and job details access 4de8550 and the unified match-review workflow 5dfefa3 and the Jobs redesign a858f97 and the fictional candidate portraits ddb4e3f, the approved Dashboard redesign 92e9796, 9862269 and 771d146): the recruitment intelligence and matching workflow (Matches, candidate review with job and CV evidence, simulated learning, next actions and drafts that are never sent), on top of the approved record-list designs and CSV import/export. All 838 source tests, lint, types and build passed. Deployment uses a hash router and /DataRecruit-demo/ asset base for GitHub Pages.

Source code, project documents, screenshots, historical PDFs and recordings are excluded. The ten candidate portraits are AI-generated images of fictional people, generated under the project owner's ChatGPT account (OpenAI terms checked 8 October 2026); they are presentation only. Brand remains a working concept. Nothing in the demo is validated recruitment workflow.
